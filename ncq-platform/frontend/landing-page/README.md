# NCQ Platform Landing Page

A modern, responsive landing page showcasing NCQ Platform's enterprise SaaS solutions for the Saudi Arabian market.

## 🌟 Features

### Hero Section
- Animated gradient background with floating elements
- Eye-catching headline with gradient text
- Product highlights with color-coded indicators
- Social proof badge (1000+ businesses)
- Clear CTAs for trial and demo

### Products Showcase
- **NCQ Payment Gateway**: SAMA-compliant payment processing
- **Blockchain Medical Records**: Secure healthcare data management
- **Hospital Management System**: Complete healthcare facility solution
- **IoT Platform**: Smart city and industrial automation
- **Smart Hospitality Suite**: AI-powered hotel management

### Professional Services
- Custom Development
- Cloud Migration
- Consulting Services
- UI/UX Design
- Security Audits
- Training & Support

### Key Sections
- **Features**: 12 key platform benefits
- **Pricing**: Three-tier pricing model (Starter, Professional, Enterprise)
- **Contact**: Form and office information
- **Footer**: Comprehensive links and social media

## 🎨 Design Features

- **Responsive Design**: Mobile-first approach
- **Dark Mode**: System preference detection
- **Animations**: Smooth scroll-triggered animations with Framer Motion
- **Glass Morphism**: Modern UI with blur effects
- **Gradient Elements**: Eye-catching color transitions
- **Interactive Elements**: Hover effects and micro-interactions

## 🔗 Navigation Links

The landing page includes smooth scroll navigation to:
- Products (`#products`)
- Solutions (`#solutions`)
- Features (`#features`)
- Pricing (`#pricing`)
- About (`#about`)
- Contact (`#contact`)

## 🎯 CTAs and User Flow

1. **Primary CTAs**:
   - "Start Free Trial" → User Portal Registration
   - "Get Started" → User Portal
   - "Admin Login" → Admin Dashboard

2. **Secondary CTAs**:
   - "Watch Demo" → Demo video (placeholder)
   - "Learn More" → Product details
   - "Schedule a Demo" → Contact form
   - "Contact Sales" → Contact section
